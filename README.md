# Flow Break
5-minute flow-break app (creative · movement · journaling). Next.js shell serving the prototype in `public/app.html` at `/`.

- Dev: `npm install && npm run dev`
- Add `?proto` to the URL for the prototype bar (jump menu, fast timer, demo gallery).
- Next step: port screens to React components + Supabase (auth, photo storage, realtime presence).
