# Flow Break

A five-minute reset app: draw, move or write, always starting with three slow breaths.
Guest-first, with an optional save-your-progress sign-in. Built by Borderless Bo.

This is the clickable prototype as a static site (no build step). Open `index.html`, or deploy to Vercel with Framework preset "Other".

- Add `?proto` to the URL to show the prototype tools (screen jump menu, fast timer, demo gallery).
- Prototype only: sign-in is simulated (demo code 123456) and the "flowing with you" count is simulated.
